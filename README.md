# Ada Foundation

Website for the Ada Foundation, supporting education, health, clean water, livelihoods and coastal protection in Ada, Greater Accra Region, Ghana.

A single static page (`index.html`) with no build step. Open it in a browser, or serve it with GitHub Pages.

## Before going live

- Replace the placeholder address, phone and email in the footer.
- Replace the example 2030 goal figures with the foundation's own.
- Connect the donate button to a payment provider (for example Paystack or mobile money) and the volunteer form to a form service.
